description: Añadir cultivo nuevo (wiki + app sincronizadas) end-to-end
---

Invoca skill `add-new-cultivo`.

Pide al user (en este orden):
1. **Nombre cultivo** (obligatorio)
2. **Categoría** (planta / hongo / fermento / etnobotánica)
3. **Modos** (si aplica: interior/exterior, kit/manual, etc)
4. **Color preferencia** (opcional, hex o keyword)
5. **Referencias extra** (opcional, URLs/libros)

Confirma plan antes de proceder. Después corre pipeline 8 fases del skill.
